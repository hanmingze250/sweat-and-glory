Sweat & Glory 隱私權政策

生效日期： 2026年10月19日
最近更新： 2026年10月19日

本隱私權政策適用於 iOS 遊戲 Sweat & Glory（App Store 名稱 Sweat & Glory: Pixel Walk RPG，以下稱「本遊戲」）。本遊戲由位於中國大陸的個人開發者茆添翔（Mao Tianxiang，以下稱「我們」）開發及提供。

一、重點摘要

  • 我們（開發者）不蒐集你的資料，也拿不到你的資料。 本遊戲沒有開發者伺服器，沒有帳號系統，沒有統計、當機分析或廣告工具，也不追蹤你。你的遊戲資料儲存在你的裝置上；開啟 iCloud 備份後，也會儲存在你自己的 iCloud 帳號中；面對面對戰和分享紀念卡時，部分資訊會直接傳給對方（見第四、五、六節）。只有在你主動寄電子郵件聯絡我們時，我們才會收到你的電子郵件地址和郵件內容（見第七節）。
  • 健康資料只讀取、只在你的裝置上使用。 本遊戲從 Apple「健康」讀取的資料，只用於在你的裝置上計算遊戲內的成長和進度，以及在遊戲中顯示（各類資料的具體用途見第二節第 1 條），不會上傳給我們，不用於廣告或行銷，不出售，也不提供給任何第三方。
  • iCloud 備份預設為關閉。 開啟後，備份會儲存在你自己的 iCloud 帳號中，我們無法存取。備份只保存遊戲進度，不包含從「健康」讀取的紀錄（見第四節）。
  • 面對面對戰是裝置之間直接連線。 「對戰」頁在前景時，附近的裝置能看到你的玩家名稱和職業等少量資訊（見第五節）。
  • 沒有廣告。目前版本沒有 App 內購買。
  • 本遊戲是娛樂產品，不是醫療器材，不提供任何醫療建議或診斷。遊戲中的數值只用於遊戲玩法。

二、本遊戲在你的裝置上讀取和使用的資料

1. 健康資料（Apple「健康」/ HealthKit，只讀取，需經你授權）

經你授權後，本遊戲會讀取以下類型：

  • 步數
  • 步行 + 跑步距離
  • 活動能量
  • 睡眠分析（臥床、入睡、深層睡眠、淺層睡眠、快速動眼期）
  • 體能訓練：只讀取跑步、游泳和騎乘，用來計算運動分鐘數和有氧分鐘數

用途： 只在你的裝置上用於遊戲玩法和遊戲內顯示。各類資料的用途如下：

  • 步數： 按天換算成角色的永久生命值（HP，每天有上限）和經驗值（例如每日達到 10,000 步可獲得 100 經驗值；連續達標每天額外 +2%，最高 ×1.6），當天獲得的榮譽（商店貨幣）也由此計算。步數還用於步數類勳章、轉職門檻、職業契合度、練習賽的生命值預估，以及主頁、戰報和每日提醒中的步數顯示。
  • 睡眠： 某晚睡滿 7 小時，當天獲得的經驗值有少量加成。睡眠還用於睡眠和早起勳章、牧師和達人的轉職門檻、牧師的每日經驗值倍率、職業契合度，以及睡眠顯示。睡眠不影響戰鬥屬性。
  • 體能訓練： 換算成有氧分鐘數，用於遊俠、刺客和達人的轉職門檻、職業契合度，以及健康數據頁和戰報中的顯示。體能訓練不影響生命值和經驗值。
  • 距離、活動能量： 只在健康數據頁顯示，不影響玩法。

轉職門檻和職業契合度使用最近 7 天的資料。在「健康」App 中手動加入的步數和體能訓練不計入。某晚如果只有手動加入的睡眠紀錄，或沒有區分睡眠階段的紀錄，這晚的睡眠分數會按較低的上限計算，也不會獲得睡滿 7 小時的經驗值加成。

我們不會： 將健康資料上傳到任何伺服器；將健康資料用於廣告、行銷或資料探勘；出售健康資料；向第三方揭露健康資料；向「健康」寫入任何資料（本遊戲只申請讀取權限）。

2. 動作與健身（裝置計步器）

當天「健康」中沒有步數時，本遊戲會透過 iOS「動作與健身」讀取裝置的計步資料補上（兩者不會相加）。補上的步數和「健康」步數用途相同；原始計步資料不單獨儲存，只儲存由此換算出的生命值、經驗值、榮譽和勳章，同樣只在裝置上處理，不會上傳。會跳出「動作與健身」授權的只有計步功能，本遊戲不使用 iOS 的動作活動辨識。

另外，角色立繪會隨手機傾斜輕微平移（視覺效果，不需授權）。為此本遊戲會即時讀取裝置的姿態資料，只在本機當下使用，不儲存、不上傳、不廣播，也不影響任何遊戲數值；系統開啟「減少動態效果」時，這個效果會停用。戰鬥只用觸控操作，不使用體感或動作操控。

3. 你在遊戲中建立的資料

包括年齡、性別、職業、角色外觀、自訂玩家名稱、遊戲進度、對戰紀錄、勳章、商店物品和遊戲設定。這些資料儲存在你的裝置上；如果你使用 iCloud 備份，也會儲存在你自己的 iCloud 帳號中（見第四節）。年齡用於遊戲內的數值換算和職業相關計算（例如未成年玩家的步數計算規則，見第九節）。我們無法存取這些資料。

4. Game Center

本遊戲可以使用 Apple Game Center 登入，但不登入也能完整遊玩；不登入時，玩家名稱會顯示為「Player」加 4 位隨機數字。Game Center 的登入由 Apple 處理；本遊戲只在你的裝置上讀取你的 Game Center 暱稱，作為玩家顯示名稱。本遊戲不會讀取你的 Game Center 好友名單，目前版本也不使用 Game Center 排行榜。Apple 對 Game Center 資料的處理適用 Apple 的隱私權政策。

5. 相機

相機只用於掃描「紀念卡」QR Code。辨識在裝置上即時完成，本遊戲不會將相機畫面傳送給我們。

6. 區域網路和藍牙

只用於面對面對戰時尋找和連線附近的裝置（見第五節）。第一次進入「對戰」頁時，iOS 會詢問是否允許存取區域網路。iOS 也可能詢問藍牙權限：允許後，系統可以用藍牙探索和連線附近玩家；本遊戲本身不會透過藍牙讀取其他裝置或配件的資料。區域網路不會廣播你的裝置名稱，但附近的人能看到你的玩家名稱（見第五節）。

7. 通知

本遊戲只使用在裝置上設定的本機通知（例如每日報告、提醒），沒有遠端推播伺服器。你可以隨時在 iOS 設定中關閉。

8. 本遊戲不使用的資料

本遊戲不使用你的位置、聯絡人或廣告識別碼，目前版本也沒有購買紀錄。

三、我們不蒐集、不分享、不出售你的資料

依照 Apple「App 隱私權詳細資訊」頁面的定義，「蒐集」是指將資料從裝置傳出，並讓開發者或其第三方合作夥伴能在超出即時處理所需的時間內存取（https://developer.apple.com/app-store/app-privacy-details/ ）。依照這個定義，我們不蒐集你的資料，本遊戲在 App Store 上的隱私權標籤是「未收集資料」：

  • 我們沒有伺服器，也沒有帳號系統。
  • 本遊戲沒有加入任何統計、當機分析、廣告或追蹤工具，因此沒有第三方會透過本遊戲取得你的資料。
  • 我們不出售任何資料，也不將任何資料用於廣告。

這並不表示沒有任何資料離開你的裝置。以下幾種情況，資料會離開裝置，但我們（開發者）和任何第三方合作夥伴都拿不到：

  • 開啟 iCloud 備份後，備份儲存在你自己的 iCloud 帳號中（見第四節）；
  • 面對面對戰時，玩家名稱等資訊會直接傳給附近的對方裝置，對方裝置會保存部分對局紀錄（見第五節）；
  • 你主動分享的紀念卡，由接收方或你使用的分享管道處理（見第六節）。

本遊戲使用的「健康」、Game Center、iCloud、面對面連線（MultipeerConnectivity）等，都是 Apple 提供的系統功能，由 Apple 依其隱私權政策處理。如果你在 iOS 中開啟了「與 App 開發者分享」分析資料，Apple 可能向開發者提供經彙整的當機和使用統計，這由 Apple 處理，不是本遊戲蒐集的資料。

四、iCloud 備份

  • iCloud 備份使用你自己 iCloud 帳號中的 iCloud 鍵值儲存。我們無法存取你的 iCloud 帳號或其中的資料。
  • 預設為關閉。 只有在你於「我的」> ⚙「設置」>「備份」中開啟「iCloud 雲存檔」後才會備份。未登入 iCloud 時無法開啟。
  • 備份內容： 每台裝置只保存一份備份，備份標籤一律顯示為「iPhone」，不記錄裝置名稱。備份包括：
    • 角色資料：精確年齡（整數歲數）、性別、職業、角色外觀、建立時間，以及轉職試煉紀錄（試煉中的生命值部分由步數換算而來）；
    • 玩家名稱；
    • 練習賽成績和正式對局紀錄（含對手的玩家名稱）；
    • 已解鎖的勳章，以及勳章相關的對戰統計；
    • 商店物品；
    • 各項設定，例如語言、音效、震動、每日戰報和提醒時間，以及首次啟動等標記；
    • 「永恆瞬間」中的紀念卡：每張卡的公開部分（見第六節）、卡上的玩家名稱和卡片來源，不含加密存檔；
    • 用來區分和校驗備份的資訊：隨機產生的裝置編號、你的 iCloud 帳號識別碼的不可逆雜湊值、儲存時間和校驗值。
  • 成長進度只保存累計總值。 備份不包含從「健康」讀取的紀錄，例如步數、睡眠、體能訓練明細。由這些資料換算的 HP、經驗值和榮譽只上傳累計總值，不含逐日數值。最近 7 天裡哪幾天有結算，仍能從保留的日期看出來，但這些日期對應的數值都是零。
  • 不上傳的內容： 單日最高步數，以及達到步數目標、睡眠目標和早起的日期，都不會上傳。因此從備份復原後，連續達標天數會從頭計算。備份也不包含權限狀態。
  • 紀念卡金鑰： 沒有開啟「iCloud 雲存檔」時，用來加密紀念卡的金鑰只保存在本機的 iOS 鑰匙圈中，不會同步到其他裝置；開啟「iCloud 雲存檔」後，才會寫入你的 iCloud 鍵值儲存。
  • 刪除： 在「我的」> ⚙「設置」>「備份」>「備份管理與復原」中選擇備份，點「刪除備份」。其他舊裝置留下的備份不會自動刪除，也可以在這裡手動刪除。

五、面對面對戰

面對面對戰透過 Apple 的 MultipeerConnectivity 在附近裝置之間直接連線，需要開啟 Wi-Fi，系統會自動選擇 Wi-Fi、點對點 Wi-Fi 或藍牙。不需要連上網路，資料也不會經過我們的伺服器。

  • 自動廣播（附近裝置可見，未加密）： 只有「對戰」頁在前景時，你的裝置才會向附近廣播。附近的人能看到你的玩家名稱（作為連線名稱，最多顯示前 12 個字元）。在大廳和附近模式下，廣播還包括對戰模式、隨機座位編號和職業；手動建房時只有連線名稱。廣播不包含等級、榮譽、勳章、裝置名稱或任何健康資料。
  • 連線後（加密傳輸）： 雙方裝置會交換開始對戰所需的資訊：玩家名稱、職業、性別、角色外觀、戰鬥屬性（生命、攻擊、防禦、爆擊、閃避、格擋），以及版本號、規則校驗值、亂數和對局操作。戰鬥屬性是由遊戲進度計算的數值，其中生命值部分由步數換算而來，但不包含步數、睡眠等健康紀錄本身。連線工作階段強制加密。
  • 連線時不會驗證對方身分，請只和你當面確認過的人對戰。
  • 對方裝置會保存： 正式對局結束後，對方裝置會保存你的玩家名稱、對局勝負、獲得的積分、完成時間和對局編號，沒有自動刪除期限；如果對方開啟了 iCloud 備份，這些紀錄也會同步到對方的 iCloud。你的外觀、性別和戰鬥屬性只在對局中使用，不會保存在對方裝置上。

六、紀念卡（QR Code 分享）

紀念卡包括對戰勝利後自動產生的「勇者卡」，以及解鎖勳章後可以產生的「成就紀念卡」，都保存在「永恆瞬間」中。

只有在你主動分享或掃描紀念卡時，相關資訊才會離開你的裝置。你將紀念卡分享出去之後，會由接收方或你使用的分享管道處理，我們無法控制。

  • 公開部分（任何人掃描都能讀到）： ①卡片資訊：格式版本、卡片 ID、卡片編號、類型（勝利或成就）、產生時間，成就紀念卡還有對應的成就，以及整張卡的校驗值；②角色：職業、性別、外觀、等級；③戰鬥屬性：生命、攻擊、防禦、暴擊、閃避、格擋（生命值部分由步數換算而來）；④戰績：勳章、對戰場數（練習賽和正式賽合計，含輸和平手）和正式賽的目前連勝數（輸或平手會歸零）。QR Code 的公開部分不包含玩家名稱。
  • 分享圖片： 用「分享圖片」分享時，圖片正面會顯示你的玩家名稱，背面是 QR Code。
  • 加密部分： 在本機產生紀念卡時，只要本機登入了 iCloud（與「iCloud 雲存檔」開關無關），QR Code 裡就會附帶一份加密的資料：你的玩家名稱，以及用於在同一個 iCloud 帳號下復原的存檔備份。玩家名稱只在加密部分裡，不會以明文出現在 QR Code 中。這份存檔和第四節的備份一樣已經降低了精度：不含從「健康」讀取的紀錄，也不含逐日數值；但仍包含你的精確年齡、性別、職業、外觀、轉職試煉紀錄、HP / 經驗值 / 榮譽的累計總值、你的玩家名稱和對手的玩家名稱。QR Code 容量不足時，不含存檔備份，只保留公開欄位和加密的玩家名稱，這張卡就不能用來復原存檔。本機沒有登入 iCloud 時，QR Code 裡只有公開部分。只有能取得同一 iCloud 帳號中紀念卡金鑰的裝置才能解密。加密資料旁邊還附帶四項不加密的輔助資訊，掃描的人也能讀到：①每張卡隨機產生的鹽值；②用這個鹽值和你的 iCloud 帳號識別碼算出的不可逆雜湊值，用來判斷掃碼裝置是不是同一個 iCloud 帳號。每張卡隨機加鹽，雜湊值各不相同，不同的卡無法透過它互相關聯；③金鑰編號，只是金鑰存放位置的隨機編號，單獨拿到它解不開任何內容；④這張卡是否帶存檔備份的標記。
  • 本版本之前產生的卡： 在本版本之前的測試版本中產生並分享出去的紀念卡，加密部分仍是當時的完整存檔，其中包括由健康資料換算的逐日進度（例如每天獲得的 HP、是否達標、單日最高步數，以及達到步數目標、睡眠目標和早起的日期）。這些卡已經在你分享到的地方，我們無法收回或修改。此外，本版本之前的測試版本產生的卡，明文的帳號雜湊值沒有加鹽：同一帳號產生的這些卡，這個值相同。
  • 請謹慎分享： 加密存檔別人無法解密，但它仍是你的遊戲資料的副本。請只把紀念卡分享給你信任的人，不要公開發布帶有存檔的紀念卡。

七、你聯絡我們時

如果你寄電子郵件給我們，我們會收到你的電子郵件地址、郵件內容，以及你主動提供的其他資訊（例如裝置型號）。這些資訊只用於回覆和解決你的問題，不用於廣告，也不會出售或提供給他人。郵件存放在我們使用的電子郵件服務（微軟 Outlook.com）中，只在處理你的問題所需的期間保留；你可以隨時要求我們刪除。請不要在郵件中傳送健康資料。

九、兒童

本遊戲的年齡分級為 13+，不以未滿 13 歲的兒童為對象。本遊戲不蒐集任何人的個人資料，包括兒童。如果你在遊戲中填寫的年齡為 13–17 歲，生命值和榮譽只按每天 6:00–22:00 之間的步數計算，每日上限也較低；每天是否達到 10,000 步（決定當天經驗值）仍按全天步數判斷。如果你是家長或監護人，對孩子使用本遊戲有疑問，請透過第十五節的方式聯絡我們。

十、資料保存和刪除

  • 我們這邊： 本遊戲不會將資料傳給我們。我們只保存你主動寄來的郵件（見第七節），你可以要求刪除。
  • 你的裝置： 刪除本遊戲會刪除儲存在本機的遊戲資料。iOS 鑰匙圈中用來區分裝置的隨機編號只保存在本機、不會同步到 iCloud；沒有開啟「iCloud 雲存檔」時，紀念卡金鑰也只保存在本機鑰匙圈中。鑰匙圈中的這些資料可能在刪除本遊戲後仍保留在裝置上。
  • iCloud 備份： 可在遊戲內刪除（見第四節）。
  • 「健康」中的資料： 由 Apple「健康」管理，刪除本遊戲不會刪除「健康」中的資料。
  • 已送出的資訊： 對方裝置保存的對局紀錄（見第五節），以及你分享出去的紀念卡，不在我們的控制範圍內。
